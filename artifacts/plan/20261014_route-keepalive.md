# 看板与工时页面路由保活方案

## Summary
保留两个页面实例及数据、筛选、详情、滚动位置。普通路由返回不请求；离开时加载与计算继续完成。

## Implementation Plan
- RouterView 插槽配合 KeepAlive，仅缓存 BoardPage、HoursPage，稳定路由标识作键。
- 初次挂载加载，重新激活仅在数据来源变化时刷新；隐藏时延后配置驱动的请求和重算。
- 看板按项目 ID、范围、凭据版本识别变化；成员及项目展示信息只更新展示。
- 工时按现有查询键识别变化；规则变化复用快照重算。激活检查上海日期，跨日更新查询。
- 隐藏期间旧加载继续，来源不匹配结果不可展示；卸载释放资源。
- 激活恢复滚动并测量矩阵视口。

## Test Plan
真实 Router 覆盖往返请求次数、状态保留、后台完成、配置延迟更新、规则重算、凭据失效、跨日、手动刷新及卸载；运行回归、类型检查、构建和桌面验收。

## Assumptions
仅运行期保活，不增加定时刷新；查询缓存过期不触发路由返回刷新。
