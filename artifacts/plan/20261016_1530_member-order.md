# 展示成员排序实施方案

## Summary

设置页支持拖拽及前移／后移调整成员顺序，自动保存；看板成员分组、工时矩阵及成员筛选选项统一遵循此顺序。

## Implementation Plan

- 将已配置成员改为纵向列表，显示序号、拖拽手柄、姓名、工号及前移／后移、移除按钮。首尾禁用对应移动按钮，拖拽时标明插入位置。
- 在 useSettings 中新增按成员工号移动位置的方法，支持插到目标成员之前或之后。复用现有串行保存队列，保存成功后更新共享状态；失败保持原顺序并显示错误。排序保存期间禁用排序操作。
- 直接使用现有 members 数组顺序持久化，无需新增配置字段、升级 schema 或修改后端。旧配置保留原数组顺序，新成员追加到末尾。
- 看板组件和布局输入增加可选的 memberOrder 成员键列表，由页面传入配置顺序，替换实际页面的姓名排序。未指定顺序时保留现有排序；成员组内任务排序及无任务成员的展示规则保持现状。
- 工时计算结果保留输入成员顺序，取消按不足天数排序；筛选及虚拟滚动保持该顺序。
- 仅调整顺序时，看板重新布局，工时复用已有快照重算，不重新请求 TAPD；兼容页面保活，返回页面后展示最新顺序。

## Test Plan

- 配置：排序保存及重新加载后顺序一致；新增、删除不打乱其他成员；保存失败保持原状态，后续操作仍可成功。
- 设置页：拖拽向前／向后移动、前移／后移按钮、首尾边界、取消拖拽和保存失败提示。
- 看板：配置顺序覆盖姓名顺序；同名成员按工号区分；筛选、折叠后保持顺序，多负责人任务归属不变。
- 工时：不足天数不同也按配置排序；筛选和虚拟滚动保持顺序，各成员工时统计值不变。
- 跨页：两个页面加载后进入设置排序，再返回核对顺序、筛选和详情状态，并断言没有新增数据请求。
- 在 iTerm 中执行相关回归测试及生产构建，保留日志。

## Assumptions

- 排序为本机全局展示设置，沿用现有自动保存方式。
- 工时页面统一按成员配置顺序展示，替代现有不足天数优先顺序。
- 本次不增加按姓名、工号或工时指标切换排序的功能。
