# 工作日工时单元格展示优化方案

## Summary
过去按当天花费，今天及未来按当天花费加当天剩余分配。工作日达到或超过配置目标为绿色；过去不足红色，今天及未来不足橙色。非工作日保持灰色。

## Implementation Plan
在HoursPage.vue独立计算展示颜色，不更改每日计算结果、业务状态、数据完整性、超额文字与统计。待确认仍按已知数值着色，保留原因；未知不足不计入确定不足。更新图例。沿用数值精度及北京时间。

## Test Plan
覆盖三种日期的不足、等于、超额，完整与不完整数据，7.5h目标及边界；非工作日加班不变。执行组件回归、类型检查、构建及桌面配色核对。

## Assumptions
不更改后端接口、配置、Worker类型、未来记录接纳或分配算法。
