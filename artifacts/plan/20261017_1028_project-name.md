# 项目名称自定义实施方案

## Summary

在设置中直接编辑项目配置名称，看板及工时页统一显示最新配置名称。改名仅影响本应用，保存后持久化，不修改 TAPD 项目。

## Implementation Plan

- 设置项目行增加编辑、名称输入框、保存和取消。保存去除首尾空白，空名称报错，未变化不写入；允许同名项目，项目 ID 不变。
- 复用串行持久化，updateProject 返回成功状态。保存期间禁用当前编辑操作；成功退出，失败保留草稿并支持重试。
- 继续使用 ProjectConfig.name，不升级 schema；新增项目默认 TAPD 名称，读取列表不覆盖配置名称。
- 看板筛选、任务标题、悬停提示及选中详情沿用最新配置名称。
- 工时每日明细、待安排任务及问题提示按项目 ID 解析当前名称。HoursIssue.message 仅保留正文；每日原因传递 message 和可选 projectId；完整失败也保留结构化问题。
- 改名不触发 TAPD 查询或工时重算；保留保活页面筛选、详情、折叠和滚动。

## Test Plan

- 覆盖成功、取消、空白、trim、失败重试及持久化。
- 旧名称任务快照及问题快照下，各展示入口使用新名称。
- 真实路由测试查询与计算次数、页面状态、项目 ID 与链接不变。
- 前端回归、生产构建、桌面编辑与跨页及重启持久化验收。

## Assumptions

- 不保留独立 TAPD 原名或恢复原名功能。
- 离开设置丢弃未保存草稿；无法查到项目时显示项目 ID。
