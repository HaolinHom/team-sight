# 成员请假日历配置升级方案

## Summary

将“成员整日请假豁免”升级为“成员请假配置”：通过月历选择日期，在弹窗中添加多名成员，分别填写请假工时，默认 8h。请假小时扣减当日工作目标，配置继续通过“保存工时配置”统一保存。

## Implementation Plan

### 日历与编辑交互

- 使用独立日历组件替换逐条配置列表，保留每日规定工时的位置与样式调整。
- 默认北京时间当前月、周一开头，支持上月、下月、月份选择、返回本月及今天标记。
- 日期单元格按成员配置顺序显示姓名及小时，多人时内部滚动。
- 点击日期打开弹窗，支持多成员、单独工时（默认8h）、可选说明、修改及移除；同日同成员只允许一条。
- 弹窗确定仅更新草稿；取消、关闭、Esc放弃修改。支持键盘、焦点限制和关闭后焦点恢复。
- 无成员时提示先添加；跨月保留草稿，修改显示待保存，统一保存后持久化。

### 数据与计算

- 请假记录新增必填数值 hours，保留 staffId、date、note；小时必须为正有限数，支持小数。
- 工作日目标为 max(每日规定工时−请假工时,0)，非工作日目标仍为0；新记录固定默认8h。
- 统计按剩余目标分配，保留实际填报、单日任务及截止日超额规则。
- 非工作日有个人请假时不参与末尾休息日加班分配。
- 工时结果增加 leaveHours；工时页展示请假工时和扣减目标，区分工作日请假豁免与非工作日。
- 沿用持久化和Worker，成功发布配置后复用已有快照重算；失败沿用错误提示及草稿恢复行为。

## Test Plan

- 日历：跨月跨年、闰年、北京时间今天、多成员、默认8h、小数、重复成员、修改移除、取消及焦点。
- 保存：弹窗不写盘、跨月草稿、保存重载、失败恢复及再次保存。
- 统计：部分及全部请假目标、实际保留、剩余容量和截止日超额。
- 集成：展示及达标判断、保活重算不新增TAPD查询。
- 相关测试、全量前端回归、生产构建及macOS桌面日历、弹窗、重启持久化验收。

## Assumptions

- 当前无旧请假配置，不设计历史迁移，同步更新测试样本。
- 仅支持单日，不增加连续日期、重复请假、导入或审批。
- 不增加第三方日历库，不调整TAPD、Rust存储接口或甘特图布局。
