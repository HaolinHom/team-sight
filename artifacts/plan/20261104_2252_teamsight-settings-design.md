# TeamSight 设置页重新设计实施方案

## Summary

重新设计 MCP Apps 设置页的布局、层级与控件。指定配置只渲染该表单；保留修订检查、局部保存、凭据隔离及全部现有设置能力。甘特图、业务计算和 TAPD 接口不在本轮改动范围。

## Implementation Plan

设计基线：

- 主色 #EB732D；页面 #FFFFFF、次级区域 #F5F6F8、主文字 #20252B、辅助文字 #626B75、分隔 #E4E7EB。状态色沿用现有语义。深色使用对应中性底色；仅设置资源使用该配色，不改变分析资源。
- 字体采用 PingFang SC（中文）与宿主／系统无衬线字体，标题 22px/650、表单标签 13px/600、正文 14px、辅助文字 12px。全部左对齐，数字使用等宽数字宽度；不加载外部字体。
- 比较了“全部等宽卡片网格”和“按工作用途排列的分类清单”。前者会重复现有模板感并让状态分散，选择后者。按“接入与团队”“工时与日历”“高级设置”组织，图标用于识别类型，状态摘要右对齐。
- 项目／成员采用表格式对齐的阅读行，集中名称、身份／别名、开关与操作；编辑展开后采用标签与字段分栏。窄宽度改为上下布局，保留明确的操作区域。
- 原始复选框用于多选；启用状态使用带文字的开关；排序按钮合并为紧凑操作；颜色使用小色块及预设；工时使用带单位的数值步进；删除在编辑区二次确认；令牌可按需显示但保存及离开后清除。
- 分组使用可展开的分组面板，显示默认／测试标记和成员数，成员多选用可点击的姓名行。写入字段提供常见字段选择，额外字段在高级编辑保留。
- 底部操作区稳定展示草稿状态、取消和保存；错误／成功反馈靠近操作区；同步等立即执行动作继续保护未保存草稿。

自评修订：不采用通用管理后台侧栏，不引入仪表盘数字或装饰性标题；设计特征集中于“对齐的配置行与局部编辑”，橙色只承担操作和选中语义。标题不增加字间距或营销文案。

实现仅调整设置组件及设置专用样式／图标，必要时刷新设置资源版本以避免缓存。构建验证后更新已安装 MCP 的对应界面资源，保留现有数据与连接。

## Test Plan

- 设置组件回归，针对新控件检查开关、步进、删除确认及表单值传递。
- UI 类型检查和单文件构建；确认定向表单无其他类型内容。
- 隔离 SDK 浏览器验证项目编辑保存重开、成员与分组控件、工时设置；检查常规／窄宽度、浅／深色及键盘焦点。
- 版本资源及已安装服务读取检查；分别记录浏览器与 Codex 原生宿主验收边界。

## Assumptions

用户本次要求已授权设置 UI 的实现。沿用现有 orange 品牌色、工具契约与配置规则，不调整甘特图、业务数据及 TAPD 写入行为，不引入 UI 依赖或外部资源。
