# 设置页精简与项目范围统一实施方案

## Summary
精简为七类设置，将账号连接、查询内容和写入权限集中至 TAPD 连接。启用且可访问项目同时作为默认查询与写入范围。MCP 忽略历史请假扣减，旧分析和旧 Tauri 行为保留。目标版本0.2.3。

## Implementation Plan
- 移除旧配置导入、请假、写入范围、其他设置分类及其表单。删除团队名称、默认查询项目及所有写入项目ID输入；保留常用字段勾选及折叠高级字段列表。
- TAPD连接按账号连接、查询内容、写入权限排列；保留局部保存、草稿保护、修订检查和凭据隔离。
- 服务端基础与批量写入共用启用且可访问项目校验，忽略旧写入项目白名单；默认查询忽略旧默认项目白名单。显式只读允许停用项目详情，仍校验TAPD权限。
- 保留操作和字段限制，新安装默认无写入操作。项目同步新增启用项目自动进入范围，写入前复核配置变化。
- MCP计算忽略exemptions，leaveHours为0，更新MCP规则版本；历史记录不清除，旧分析和Tauri原规则不变。
- 旧target write/general映射connection，leave/import映射overview；保留旧导入接口及旧资源别名，新工具说明只推荐现有分类。
- 构建0.2.3，生成macOS/Windows运行包并备份升级本机服务。

## Test Plan
验证七类入口、迁入字段保存与重开、自定义字段保留、定向渲染和冲突草稿；验证旧白名单不阻拦启用项目、停用/不可访问项目拒绝基础及批量写入、同步新增项目、写入中配置变化、操作与字段限制；带历史请假验证MCP统计/容量/普通与紧急排期不扣减、旧快照可读和legacy计算不变；完成包级测试、构建、隔离协议验证及浅/深色和窄屏截图，明确原生宿主和Windows未实测边界。

## Assumptions
查询工作项类型的已有值、默认值和作用范围不变。兼容存储团队名称、旧项目名单、请假数据和导入接口但不提供旧表单。甘特图布局及排期策略不改。不提交Git或修改正式knowledge。
