# 旧版 Tauri 与兼容代码退役实施方案

## Summary

将仓库收敛为 MCP 项目，移除独立 Tauri App、旧配置导入、旧工时算法和旧 MCP 兼容入口，升级本机服务至 0.3.0。当前 MCP 的配置、TAPD 查询与写入、工时分析、普通排期、紧急模拟、甘特图、报告和恢复功能保持；历史分析原样只读。

## Implementation Plan

- 删除根 src、src-tauri、旧 HTML/Vite/TypeScript 配置、专用测试、图标、工时验证脚本。移除 Tauri/Rust/router 依赖；根 build/test 转发完整 MCP；Vue 由 MCP UI 解析。保留历史文档、知识及报告。
- 删除 probe 工具、旧配置导入、list_workspaces 别名、p0/p1a/p1b 脚本及资源别名、旧设置目标、TEAMSIGHT_P0 环境变量。资源仅提供 0.3.0；停止接口改为 /_internal/stop。
- 计算统一 MCP hours v3；删除 legacy 和请假算法。schema v6 删除 exemptions 和两个旧项目白名单，新工时删除 leaveHours。旧分析不重算、不改文件；非当前规则分析不得用于新模拟或写入。
- 新数据库 teamsight.sqlite / user_version 4，钥匙串 TeamSight.MCP，默认目录 .local/teamsight-mcp。移除原型配置镜像，凭据引用独立保存。
- 提供显式离线 migrate --from --to，仅接受 MCP DB v3 / config v5；源停止、目标不存在；保留 revision、有效配置、访问令牌、业务记录和所有文件，凭据只经钥匙串复制。失败清理目标新凭据，源不变。
- 构建和隔离验收后停止现有 cn.teamsight.mcp LaunchAgent，备份启动配置，将生产 data 迁至 data-mcp，安装 versions/0.3.0，原端口和访问令牌启动。旧数据库、凭据和运行包保留回退；失败切回原版本和数据。
- 更新当前文档、打包清单；不执行 Git 提交或推送，不执行真实 TAPD 写入。Windows 保持支持但不声称实机验证。

## Test Plan

- 基线 0.2.6：构建及 107 项测试通过。全量构建测试回归，保留 CAS、写失败回滚、凭据、鉴权、锁、重启恢复覆盖。
- 校验所有当前工具和资源及退役入口；检查无 Tauri 引用、依赖或原型产物。
- 固定样本对比当前 MCP v3 工时、容量、风险；覆盖缺预估、缺排期、部分数据、当天不足、非工作日。
- 迁移覆盖成功、运行中源、目标冲突、钥匙串失败、数据库失败、重复执行；校验配置、revision、回执、文件哈希和访问令牌。
- 设置局部保存、甘特模式、虚拟排期、悬浮抽屉、SVG/PNG/HTML 和报告回归。
- 本机 doctor、隔离 MCP、安装包哈希、宿主连接、配置凭据及历史数据核对和真实只读查询；写入及未知恢复使用隔离 TAPD。

## Assumptions

用户已确认移除旧 MCP 入口、保留历史快照、统一存储命名并迁移、同时升级本机。旧卡片需重新打开。现有数据基线 revision 23、9 项目、5 成员；实施时重新核验。验收失败停止新版并恢复旧启动配置，不覆盖升级后产生的新数据。
