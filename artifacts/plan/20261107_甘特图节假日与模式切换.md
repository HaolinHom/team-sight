# 甘特图节假日与模式切换优化方案

## Summary

完成四项界面优化，并将休息日表头及整列底色同步到 SVG、PNG、HTML 导出。节假日和调休使用分析时的日历依据，不改变工时计算结果。

## Implementation Plan

### 日历与日期底色

- 为 TeamAnalysis 增加可选的 calendar: WorkingCalendar，保存分析范围内实际采用的日历覆盖；空对象表示采用普通周历，字段缺失表示旧分析。
- teamsight_read_analysis 返回对应范围的日历数据，界面和导出统一使用 core 的 isWorkingDay 判断日期；模拟分析继承基准分析日历。
- 非工作日的日期表头和正文整列使用现有周末底色；周末调休为工作日时按工作日绘制。
- 列底色绘制在任务块、工时块和网格线下方，覆盖成员行与任务行；导出时避免被行背景遮盖。
- 今天若为休息日，保留休息日底色，通过日期强调色和今日虚线标识今天。
- 旧分析沿用普通周历，并在界面及导出说明中提示重新分析以获取准确的节假日、调休显示；不读取当前日历替换历史依据。

### 隐藏成员行的休息日零工时

- 仅隐藏落在成员姓名行、日期为非工作日、实际及预计均为 0、且没有未知状态或完整性提示的工时单元。
- 隐藏整个单元，包括底色、边框、标签及焦点入口。
- 保留休息日的非零工时、未知信息，以及关联任务行上的工时块；调休工作日保持正常显示。

### 工时底色与渐变

- 保留达标、不足、未知的现有状态颜色。
- 工时块始终具有有色填充：任务优先时填充强度为 22%，工时优先时为 30%，呈现略深的底色，并保留底层任务轮廓。
- 将填充强度与边框、侧带、标签的强调程度分开控制，避免整层透明度叠乘造成颜色过深。
- 两个方向切换均采用 200ms ease-in-out，平滑过渡工时块填充和装饰透明度，以及任务块透明度。
- 保持图层节点稳定、沿用现有前后层顺序；切换后立即更新点击和键盘焦点权限，仍只有优先层可交互。
- 遵循现有减少动态效果设置，启用时取消动画。

## Test Plan

- 日历场景：普通工作日、普通周末、工作日节假日、周末调休、跨年日期及今天恰为休息日。
- 数据场景：日目标工时设为 0 不影响工作日判定；日历关闭、来源不完整、旧分析及模拟分析符合上述口径。
- 工时场景：休息日成员行零工时隐藏；非零、未知、有完整性提示及任务行工时保留。
- 组件回归：两种模式底色、图层顺序、点击、Enter／Tab、详情抽屉与提示行为。
- 导出回归：SVG 的表头和整列底色正确，分页后仍一致；抽查 PNG、HTML 实际渲染。
- 浏览器检查：明暗主题下双向切换及快速连续切换，无闪烁、块位移或滚动位置变化；减少动态效果设置生效。
- 执行受影响的 core、server、UI 测试及 UI 类型检查和构建；浏览器实查动画，组件测试不替代视觉验收。

## Assumptions

- “节假日”隐藏零工时的规则覆盖全部非工作日，包括普通周末。
- 新分析遵循现有中国日历开关；不自动开启或刷新日历。
- 新增日历字段为可选字段，兼容已有分析 JSON，无需数据库结构迁移。
- 本轮包含界面与导出调整；安装升级、发布及 TAPD 写入不在范围内。
