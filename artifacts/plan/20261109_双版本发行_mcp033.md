# TeamSight 0.3.3 双版本发行实施方案

## Summary
同一版本同时提供自带运行时版和精简版，覆盖 macOS arm64、Windows x64，共四份发行包。自带版固定 Node 22.23.4；精简版要求 Node 22.14+、低于23、Node-API 10+。不更新本机服务。

## Implementation Plan
- 每个平台准备一次公共产物，生成 bundled/external 两种目录及 tar.gz/zip；支持指定平台、默认本机和 all；拒绝覆盖，临时准备并失败清理。
- 固定官方 Node 归档及 SHA-256，缓存至 .local，复用仍校验；仅提取可执行文件及许可证。
- 固定模式的运行辅助入口供 launch、verify、status 复用；自带版缺失损坏时失败，不回退系统 Node，清除 NODE_OPTIONS/NODE_PATH；精简版校验外部 Node。保留空格路径、参数、退出码和停止行为。
- 升级工作区、状态、MCP 及资源到0.3.3；每包生成版本与文件校验清单，记录运行时来源，区别构建和实际验收版本；四份归档另附SHA-256清单。更新当前文档。

## Test Plan
- Node22.23.4构建、全量回归及打包测试：参数、哈希、缓存、拒绝覆盖、清理。
- 四包解压、文件哈希、无符号链接及同平台公共文件一致性；Windows PE架构检查。
- macOS两种包在含空格目录执行doctor、隔离MCP、启动/状态/停止，验证SQLite、钥匙串、中文PNG及共用隔离数据兼容。
- 验证无系统Node、错误系统Node、缺失损坏私有Node和环境隔离。Windows运行及原生Apps明确待验收。

## Assumptions
不上传发布、不更新本机服务；DB v4/配置v6不变，无数据迁移；不改业务和TAPD写入；保留历史发行包，不扩展平台及Node大版本。
