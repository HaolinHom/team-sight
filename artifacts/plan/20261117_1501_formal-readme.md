# TeamSight 正式 README 与使用文档整理方案

## Summary

以普通使用者为主要读者，重写 README，并整理直接关联的安装、使用与服务文档。读者应能理解 TeamSight 的用途，完成安装、连接和首次配置，并通过对话使用主要功能。同时介绍发行包安装与 Agent 自动安装，以当前 0.3.4 实现为依据。

## Implementation Plan

- README 按项目介绍、核心功能、环境要求、安装与连接、首次配置、使用示例、数据与权限、开发与文档导航组织。采用正式中文，移除调试口吻、验收流水、内部流程及逐版本变更堆叠。
- 推荐 bundled 发行包，按 macOS arm64 / Windows x64 说明包名、校验、解压、前台启动、连接及状态检查。保留 external 版要求。
- macOS Agent 自动安装说明覆盖固定下载地址及 SHA-256 校验、后台服务、Codex 配置和重连。当前地址包含发布占位，明确发布前提，不作为可直接使用的命令。
- Windows 本地后台安装器作为进阶说明，明确需另行构建管理脚本。
- 区分本机 MCP 访问令牌与 TAPD 令牌，说明宿主认证信息传递、成员与默认分组、完成状态、工时日历和写入权限。
- 整理能力与使用说明、服务 README、macOS Agent 安装说明及其生成模板；默认示例推荐 bundled，保留 external 选项及下载校验机制。
- 使用示例覆盖个人查询、团队甘特图、风险分析、需求排期、紧急模拟、评论和报告导出。
- 历史文档、方案、测试报告和封存发行包保持原样；不修改业务 API、配置类型、安装行为或权限逻辑。

## Test Plan

- 对照源码核实功能、平台要求、命令、包名、默认配置与权限说明。
- 检查 Markdown 层级、代码块、相对链接和锚点。
- 按获取安装包、启动、连接、配置、首次查询走查完整流程。
- 核对安装说明与生成模板一致，发布占位地址不标为可用。
- 不启动或更新本机服务，不修改 Codex 配置，不执行真实 TAPD 写入；不运行完整业务测试。

## Assumptions

- 中文文档，以 Codex 为主要接入示例，其他宿主仅说明兼容要求。
- 两种安装方式说明现有能力，不新增 Windows HTTP 安装器。
- 不包含公开仓库、上传 Release 或发布脚本；实际下载入口以已发布资产为准。
- 按当前源码准确说明新安装默认授权、中国日历以及旧配置保留行为。
