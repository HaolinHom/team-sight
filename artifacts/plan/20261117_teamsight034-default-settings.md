# TeamSight 0.3.4 默认配置与 MCP 更新方案

## Summary

新安装默认勾选查询类型、写入操作、可修改字段及中国节假日与调休。已有配置原样保留。先将版本从 0.3.3 升至 0.3.4，再构建 macOS 双包并更新本机精简版 MCP。

## Implementation Plan

- 核心首次配置默认查询任务、缺陷；允许创建、修改、发表评论；允许任务名称、描述、负责人、预估工时、开始日期、结束日期、关联需求、状态八个字段；开启中国节假日与调休。年度数据继续按现有分析流程获取。
- 默认值落入新数据库，设置页展示服务端配置并同步初始化值。已有配置中的空数组、缺失权限、关闭日历和自定义字段保持原有读取行为；升级不补选。
- 根包、工作区包、服务状态、MCP 握手、Apps 标识和设置／甘特图资源 URI 统一升级为 0.3.4；工具接口、配置 v6、数据库 v4 保持不变。
- 更新当前安装及验收入口的版本引用；macOS 安装器兼容识别旧版受管安装并保留失败回退。生成新包后更新下载哈希，再生成安装脚本及说明。历史归档及报告保留。
- 生成 macOS arm64 bundled、external 两种运行包及校验清单。通过完整性、doctor 和隔离 MCP 验收后，核对正式实例归属及活动作业，停止旧实例并确认退出，备份静止数据与启动／连接配置。
- 沿用现有 LaunchAgent、外部 Node、端口和数据目录切换到新精简版；保留旧包，启动或验收失败恢复旧配置。更新后核对当前 MCP 连接的版本、39 项工具、两项资源，以及配置、凭据和历史数据。

## Test Plan

- 空目录首次读取全部默认值；保存凭据、同步项目、重启后保持。
- 已有取消选择、空权限、缺失权限、关闭日历和自定义字段保持；主动取消、保存及重开不恢复默认。
- 设置页验证首次快照勾选、局部保存、读回；日历用固定响应验证年度获取及来源缺失处理。
- 完整构建与测试、macOS 双包及安装器隔离验收，核对版本、下载哈希、旧版升级和失败回退。
- 正式服务只读验收，比较更新前后配置修订、持久数据与凭据摘要，不向 TAPD 新增业务数据。

## Assumptions

- 已确认仅新安装采用新默认值，不重置已有配置。
- 交付本机更新和 macOS 双包；不生成 Windows 包，不进行线上发布、Git 提交或推送。
