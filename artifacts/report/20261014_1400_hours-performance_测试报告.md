# 工时性能与界面响应性优化测试报告

## Summary

2026-10-14 对已确认工时性能方案实施并验证。主要改动：Rust 异步命令加 spawn_blocking 后台 HTTP、生产 Web Worker 统计、成员／任务／日期索引、活动任务分配、短期查询缓存、过期加载取消、全局请求并发限制、加载进度、大矩阵可见区域渲染和长明细分批展示。统计业务规则保持原有口径。

## Results

### 正确性与构建

- pnpm test：30 个文件、241 个用例全部通过，覆盖原有功能及 Worker 生命周期、缓存失效、凭据隔离、请求取消、重试取消、大矩阵 DOM 数量与滚动。
- cargo test --lib：4 个本地 Rust 测试通过，2 个需要真实凭据的既有测试默认忽略；真实数据由独立只读脚本验证。
- pnpm tauri build --bundles app：Vue 类型检查、Vite、Rust release 及 macOS 应用打包成功。
- pnpm verify:secrets：最终构建扫描 3251 文件，无令牌泄漏；git diff --check 通过。
- 100 组固定种子场景将原算法与优化算法完整结果对照；包含多人、终态、历史／未来记录、无效字段、日历覆盖、豁免和未知累计。输出相同（数值误差阈值 1e-8）。

### 同环境计算对比

Node SSR 合成数据、6 成员、任务跨度 91 天、展示 31 天；均先暖运行再测 3 次。该表是纯计算时间，不是桌面网络或渲染时间。

| 任务／记录 | 原算法 3 次 ms | 优化算法 3 次 ms | 按中位数减少 |
| --- | --- | --- | --- |
| 300／1500 | 29／27／27 | 5／4／4 | 约 85% |
| 1000／5000 | 85／84／85 | 9／8／6 | 约 91% |
| 3000／15000 | 257／257／260 | 23／19／22 | 约 91% |

### 生产 Worker

用 Node worker_threads 运行最终构建的同一个 Worker bundle，3000 任务、15000 记录：首次计算 48ms、包含数据传递往返 61ms；后两次只传规则，计算 28／24ms，往返 29／25ms。主线程 5ms 心跳在计算期间持续运行，20 次心跳的最大间隔 7ms。此测试确认生产 Worker bundle 可执行及规则重算复用快照；它不能代替 WebView 帧耗时测量。

### 真实接口与桌面

- 一项目一成员真实样本：283 个工作项、117 条记录，实际工时与记录汇总一致。1 项多人负责人身份未知提示被保留，未产生确定预测结论。
- 首次读取 34 次实际网络请求，约 2237ms；重复读取 0 次请求、32 项缓存命中、约 2.9ms；切换范围只新增 1 次实际查询、31 项缓存命中、约 125ms。上述使用真实 TAPD 网络和新聚合器，传输为只读脚本直连，不是 Rust IPC 时间。
- 桌面发布应用中，工时目录加载尚未完成（3／8）时立即切换设置页成功，无需等待整轮工时加载；返回后完成 Worker 计算并展示 8 项目、6 成员矩阵。历史／预计、项目明细及待确认原因显示正常。
- 桌面截图保存于本目录，展示固定成员列、横纵滚动、待确认格与明细。桌面人工验收基于本轮 14:10 的发布构建；随后缓存时间标注、虚拟行尺寸和重试取消的最后小修已通过最终测试、构建及生产 Worker 验证。
- 大矩阵组件测试：100 成员 × 31 日期，只生成不足 200 个日期按钮；滚动后显示后续成员和日期。默认 6 人月视图保持完整表格。

## Issues

未发现阻止交付的问题。开发验证中修复了异步结果未触发 Vue 更新、Worker 失败被取消错误覆盖、缓存时间以开始时间标注导致复用时间漂移等问题，最终回归全部通过。

真实数据中的无工号负责人、缺预估／日期仍显示待确认／待安排；优化未把不完整数据当作零工时。

## Not Tested

- 未量化 macOS WebView 的 p95 输入延迟、每一帧渲染和长任务时间，因此不宣称已经达到所有操作 100ms 内或单任务 50ms 内的量化指标；已验证加载期间切页响应及真实矩阵可用。
- Windows 原生界面、超大真实成员列表的桌面虚拟滚动未验收；大矩阵窗口与滚动由组件测试覆盖。
- 冷启动仍需真实读取工作项和逐任务累计，时间受 TAPD 数据量、网络与限流影响；本轮没有采用未经验证的项目全历史批量或增量接口。
- 取消会停止排队、后续分页和重试；已执行的 Rust 阻塞 HTTP 不会被立即中断，其结果被忽略，最多等待既有超时释放请求槽位。
- 缓存仅内存驻留，60 秒有效期，最多 512 项／40000 行；手动刷新绕过缓存。未新增持久缓存或自动增量同步。
- Worker 保留快照，规则变更仍重新构建统计索引与分配；成员／异常筛选复用计算结果，不重新执行统计。未引入独立子进程。
