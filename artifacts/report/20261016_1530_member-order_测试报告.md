# 展示成员排序测试报告

## Summary

验证展示成员拖拽与前移／后移、配置保存一致性、看板分组和每日工时成员顺序，以及路由保活后的数据复用。测试、构建通过项目脚本在 iTerm 执行，输出由 tee 保存。

## Results

- `pnpm test`：31 个测试文件、317 项测试全部通过；新增 12 项测试。
- `pnpm build`：vue-tsc 类型检查与 Vite 生产构建通过，包含工时 Worker 构建。
- `git diff --check`：通过。
- 设置页组件验证：前移／后移、首尾禁用、拖拽向前／向后插入提示、取消拖拽、自身放置、忽略外部拖入、保存期间禁用排序、保存成功前保持原顺序、失败提示与重试、重新打开后读取已保存顺序。
- 配置层验证：排序在串行队列内基于最新配置计算；新增、删除保留其余成员顺序；无效目标或位置不变不写入；保存失败不阻断后续写入。存储读回保留成员数组顺序。
- 看板验证：配置顺序覆盖姓名及工号排序；同名成员分开；未指定顺序保留原有排序；多负责人归属、任务排序、折叠与筛选后的相对顺序不变。

- 使用真实 memory Router 与真实设置页验证跨页流程：加载看板和工时后在设置调整顺序，再返回两个保活页面，分组／矩阵／工时成员选项更新；成员筛选、工时详情、看板详情和折叠状态保留。看板、工时数据请求各维持 1 次；工时计算由 1 次变为 2 次，复用原快照。
