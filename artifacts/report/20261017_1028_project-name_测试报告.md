## Results

- 前端回归：pnpm test，31 个测试文件、331 个用例全部通过。
- 生产构建：pnpm tauri build --bundles app 成功；包含 vue-tsc --noEmit、Vite 主包与工时 Worker 构建，以及 Rust release 和 .app 打包。

- 工时：快照问题只含正文；每日原因保留项目 ID、按项目和正文去重；每日详情、待安排任务、明细筛选、完整失败提示读取当前配置；未知项目回退 ID，通过回归。

- 验收清理：退出应用后恢复验收前 settings.json 原始内容，逐字节比对一致；重新打开生产包。
