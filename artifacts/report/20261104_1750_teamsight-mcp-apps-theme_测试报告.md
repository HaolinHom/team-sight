# TeamSight MCP Apps 主题配色对照报告

## Summary

对 UI 方案中的橙色主色和主要文字配色进行静态数值对照；未实施 UI。

## Results

- 主色 rgb(235, 115, 45) 对应 #EB732D；方案已改为使用橙色主色，并搭配暖中性色、青绿色实际工时与橙色系预计工时。
- 相对亮度对比度计算：默认橙底 #EB732D 与文字 #1C0F08 为 6.26:1，橙底与白字为 2.99:1；悬浮 #D86423 与按下 #D35E1B 使用 #1C0F08 时分别为 5.14:1 和 4.80:1。
- 浅色选中 #A63F09 / #FFF4EC 为 5.82:1；深色选中 #FFAF80 / #36251D 为 8.13:1。浅色警告文字／背景 #8A5104 / #FFF7E5 为 6.04:1；浅色错误 #AE3026 / #FFF1EE 为 5.87:1。
- 既有方案的蓝色主按钮描述已替换；甘特图仍无筛选入口，任务项目颜色维持由用户配置。

## Issues

未发现阻止方案讨论的问题。以上为单一色对数值计算，不代表实际组件的所有状态均符合对比度要求。
