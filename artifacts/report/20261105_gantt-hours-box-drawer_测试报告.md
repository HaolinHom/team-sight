# 甘特图工时盒子与详情交互测试报告

## Summary

完成 MCP Apps 展示层优化：单日工时盒子包围关联任务区域，状态颜色、双层优先级、右侧详情抽屉及任务简讯。工时计算、服务接口、配置和 TAPD 数据未修改。本轮仅更新源码和本地构建产物，未升级正在运行的 MCP 安装包。

## Results

- UI 测试 **38/38 通过**：15 项展示模型测试、8 项甘特图交互测试、4 项分析页回归和11项设置页回归。覆盖连续/非连续任务、多负责人、跨窗口裁剪、无排期和未知来源、跨项目/类型相同ID、原任务排序、所有工时状态。
- 交互覆盖前景层点击与键盘、背景层禁用、原生 modal dialog、Escape/cancel、关闭按钮、遮罩、焦点约束及恢复、TAPD 链接事件、提示延迟及边界、切换模式/新数据清理、iframe被宿主滚动裁剪时的抽屉位置。
- `pnpm --filter @teamsight/mcp-ui build` 通过，包括 `vue-tsc --noEmit` 和三份自包含页面构建。
- 隔离 SDK 宿主首先使用测试 TAPD 和内存凭据完成常规检查，随后只读载入已存在的十月分析快照。分页读取完整返回5名成员、395个范围相关工作项；展示模型进一步过滤可绘制任务，不将395解释为甘特图条数。
- 十月八日洪浩林的盒子坐标为 x=339、y=32、宽42、高122，包含三条关联任务，不再从成员任务区末尾起画。每日抽屉显示实际8h、目标8h及三条任务的1h、5h、2h贡献。
- 长列表中点击“总部活动申请优化”后直接显示右侧详情；Escape关闭前后横向234、纵向1008的图表滚动位置均保持不变。
- 复现并修复宿主滚动导致抽屉标题被 iframe 裁剪的问题；可见区域观测后抽屉 top=41、高719、宽400，标题及关闭按钮可见。
- 390px窄屏暗色模式下抽屉宽390px、可见高700px、正文独立滚动；全宽布局及换行正常。
- 真实鼠标移动触发悬浮简讯；Tab聚焦显示简讯，包含完整标题、项目、负责人、状态、排期、预估。修复焦点自动滚动后提示立即消失的问题。最终提示边界 left=466、right=786，位于可见区域。

## Issues

- 构建存在依赖 zod 中 PURE 注释位置的 Rollup 提示，不影响构建。
- 浏览器控制台间歇出现 MutationObserver 异常。通过 CDP 栈和脚本源确认来自 Electron preload 注入脚本（CommonJS wrapper、空URL），未定位为业务应用异常；不将隔离浏览器结果扩展为全部宿主验收。
