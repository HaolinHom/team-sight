## Summary

2026-11-06，按已确认方案实现并验证 MCP 交互甘特图及 SVG、PNG、HTML 甘特图导出。服务端在工时与风险计算结束后，独立补查工时引用的工作项资料；展示转换由 core 共享，不修改原始任务日期、负责人或计算任务集合。

缺少有效日期的工作项按成员首末实际花费日生成连续虚拟区间；负责人流转或排期外投入按实际花费日补块。同一成员同一工作项一行，虚拟条使用项目颜色、虚线及“补／按工时补充”标识。没有有效日期也没有实际工时的原有任务保留名称行。

代码、构建及隔离验证已完成；本机已安装的 MCP 服务没有替换，旧卡片不会自动更新。本次未提交或推送 Git。
