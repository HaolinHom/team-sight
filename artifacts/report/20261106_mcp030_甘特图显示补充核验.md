## Issues

原生 MCP 卡片未恢复。需刷新／重新连接 TeamSight 的 MCP 工具发现信息后，再次验证新版资源与卡片显示。此前“聊天已连接新版”仅证明工具调用访问 0.3.0，不证明宿主元数据和卡片资源同时刷新。

电脑操作工具明确拒绝控制 `com.openai.codex`，原因是该应用不允许被该工具控制；没有使用其他 UI 自动化绕过该拒绝。手动刷新连接需要用户完成。原生 UI 待验边界维持不变。
