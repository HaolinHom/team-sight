# MCP 0.3.0 artifacts 目录清理测试报告

## Summary

2026-11-07（北京时间），按用户要求清理 artifacts 中已过期的内容。以当前 MCP 0.3.0 交付、正式知识引用关系、最近知识清理记录及未解决的甘特图显示核验为保留依据，不按日期直接删除全部旧文件。

清理前工作区无未提交修改。删除 **2,394 个文件，合计 60,790,828 字节（约 60.8 MB／58.0 MiB）**，其中 256 个为 Git 跟踪文件；另移除 386 个空目录。原有文件中保留 4,342 个，新目录说明、本报告及本地清理证据另计。

全部变更位于 artifacts 内。未修改正式知识、业务代码、规则或运行服务；仓库外安装目录、生产数据、钥匙串、LaunchAgent 和升级回退备份不在本轮范围。未执行 Git 提交或推送。

## Issues

发现 **11 处清理前已存在的缺失 Markdown 链接**，主要为旧运行包地址和未留在仓库中的历史截图；另有 1 处证据目录原本为空，清理空目录后链接不再有效。已将这 12 处改为明确的“历史附件未留存”文字及原路径，不补造历史证据。清理前的缺失状态、修正明细均单独登记；最终保留文档中不存在失效的本地 Markdown 链接。新增目录说明引导使用 0.3.0 当前交付，旧报告以历史标注限定适用范围。

清理判定以“是否仍承载当前交付、知识依据或未完成问题”为准，而非扫描到旧版本字符串就全部删除。旧记录中的原安装目录、原 PID、样本数据与验收状态仅描述当时；不代表当前服务状态。
