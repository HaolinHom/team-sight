# 甘特图节假日与模式切换测试报告

## Summary

按已确认方案实现节假日/调休底色、成员行休息日零工时隐藏、工时优先浅色填充和双向渐变；同步 SVG、PNG、HTML 的休息日表头及整列底色。新增可选 calendar 日历快照，并保持历史分析只读兼容。

测试环境：macOS arm64，Node 22.23.2，pnpm 10.12.4，本机 Google Chrome headless。构建、测试、预览及验收脚本均在 iTerm 执行，并由 tee 保存日志。所有服务端/浏览器数据均为隔离 fixture，未连接真实 TAPD，也未操作用户 MCP 的配置或数据。

## Issues

- 首轮 UI 构建发现新增参数化测试中的 readonly reasons 与可变类型不兼容，已修正。
- 浏览器发现移动 SVG 层会重置局部 transition，任务颜色跳变；将动画改为稳定滚动容器上的可继承注册数值属性后，双向中间值及快速反向切换通过。
- 历史分析导出的长提示在单日窄页可能裁切，已改为两行并预留高度，补充单日 SVG/PNG 回归。
- SDK CUA 连接两次超时，改用隔离 headless Chrome 与现有 SDK 验证宿主完成浏览器验证。
- 构建存在 zod 依赖注释的 Rollup 注解提示，不影响构建通过。
- 最终未发现阻塞问题。
