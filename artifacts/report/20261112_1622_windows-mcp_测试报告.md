## Issues

已解决：

- nvm 原代理端口失效以及官方下载大文件连接不稳定；使用 7897、镜像下载及官方归档 SHA-256 比对完成安装，不关闭 TLS 验证。
- Windows PowerShell 5.1 当前有效策略禁止脚本；使用本机 PowerShell 7 的既有 RemoteSigned 策略，不修改执行策略。Windows 本地安装器明确要求 PowerShell 7。
- macOS 专属路径与 process.getuid 测试在 Windows 不适用，明确跳过；链接拒绝测试使用 junction，不要求开发者模式。
- 计划任务将域账号规范化为短用户名，改为 SID 比较。
- Set-Acl 重复应用会误要求 SeSecurityPrivilege；改为直接写入 DACL 的 .NET API，普通用户重复安装验收通过。
- pnpm 安装将仓库原先误跟踪的 `packages/tapd/node_modules/@teamsight/core` 链接替换为 Windows junction，Git 显示该已跟踪生成链接删除；运行链接存在且构建/测试通过，node_modules 原已在忽略规则中。未通过恢复占位文本破坏实际依赖链接。
